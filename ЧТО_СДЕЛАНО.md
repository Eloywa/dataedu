# DataEdu (Django) — журнал миграции

Перенос DataEdu с Next.js на Django (монолит + HTMX, тренажёр на PGlite).
Next-версия не трогается — это защищаемый артефакт 1-го года. Идём по этапам.

- Окружение: **uv**, Python 3.13, **Django 5.2.15**, psycopg 3.3, python-dotenv

  - `templates/base.html` — шапка `~/DataEdu` + моно-навигация, подвал;

  главная отображается в дизайне Terminal.

### Заметки по окружению (Windows) — важно для следующих этапов
- В системе включён **SOCKS-прокси** (Internet Settings) → uv/pip падают с «tunnel
  error». Обход: ставить пакеты с `NO_PROXY='*'` (напр. `NO_PROXY='*' uv add ...`).
- Postgres: подключаться по **`127.0.0.1`** (IPv4); `::1` (IPv6) блокируется
  фаерволом (ошибка 10013). Учётные данные БД — те же, что у Next-версии (лежат в
  `.env`, в git не входят).
- Запуск сервера: `NO_PROXY='*' uv run python manage.py runserver`.

## Этап 2 — модели и перелив данных ✅ (26.06.2026)

- Снял схему текущей БД через `inspectdb` (22 таблицы, UUID-ключи).
- Описал чистые управляемые модели по приложениям (имена таблиц/колонок совпадают
  с текущими — для прямого перелива):
  - **accounts** — `Role`, кастомный **`User`** (вход по email, `AUTH_USER_MODEL`).
  - **courses** — `Topic`, `Course`, `CourseTopic` (составной ключ), `Module`,
    `Lesson`, `CourseRating`.
  - **assessments** — `Test`, `Question`, `AnswerOption`, `TestAttempt`,
    `AnswerSubmission`, `Assignment`, `Submission`.
  - **learning** — `Enrollment`, `LessonProgress`, `Reflection`, `Activity`.
  - **gamification** — `Achievement`, `UserAchievement`.
  - Чат (`messages`) — сознательно не переносим; вью `v_student_course_progress` —
    отложена (этап 11, аналитика).
- Пересоздал пустую БД `dataedu_django` (на этапе 1 миграция шла со стандартным
  User), сгенерировал и применил миграции всех приложений.
- Management-команда **`transfer_data`** перелила данные из старой БД `dataedu`:
  **21 таблица, 1600 строк → 1600, расхождений 0**, FK-связи целы. Пароли не
  переносились (будут пересозданы штатно на этапе 3).
- `manage.py check` — без замечаний.

### Заметки
- Пароли пользователей сейчас «неустановлены» (`set_unusable_password`) — вход
  настроим на этапе 3, демо-пароли зададим там же.
- Вывод команд — только ASCII (символ `→` падал в cp1251-консоли); при запуске
  Python-утилит полезно `PYTHONUTF8=1`.
