SQL-тренажёр

PostgreSQL работает прямо в браузере. База своя у каждого и сохраняется между заходами: можно создавать таблицы, менять данные и ломать — всё чинится кнопкой «Сбросить базу».

{% comment %} Шкала загрузки. Движок весит 16 МБ и о ходе загрузки не сообщает: на общем канале студент несколько секунд смотрел на слово «загрузка» и решал, что страница сломалась. {% endcomment %}
{% comment %} Схема заполняется скриптом из information_schema, а не вписана в шаблон: раньше здесь был список из двух таблиц, и созданная студентом третья в нём не появлялась — панель врала ровно тогда, когда становилась нужна. {% endcomment %}

{% comment %} «Сбросить базу» стоит отдельно от рабочих действий и под чертой: это единственная кнопка на экране, которая уничтожает работу студента, и соседство с «Выполнить» ей не по чину. {% endcomment %}

Вернёт набор данных к исходному виду. Созданные вами таблицы пропадут.

{% comment %} Строка быстрых символов (бриф §5). Кнопки добавляет скрипт: без него вставлять нечем, и пустая полоса на экране только занимала бы место. {% endcomment %}
{% comment %} «Как выполняется» показывает запрос по шагам на диаграмме и не меняет базу. «Показать план» — тот же запрос через EXPLAIN ANALYZE, разобранный в дерево. «Замерить» повторяет запрос пять раз и сравнивает с прошлым замером: между ними студент успевает создать индекс, и разница — это и есть урок. {% endcomment %}
